The UK-EU treaty on Gibraltar applied provisionally from 15 July 2026: no passport checks at the La Linea land border, Schengen checks moved to Gibraltar airport and port. Any Gibraltar entry source dated before that describes the old regime and is a contamination risk.

**How to apply:** for any run touching Gibraltar, check the source date first; prefer gibraltar.gov.gi technical notices, exteriores.gob.es and gov.uk/foreign-travel-advice/gibraltar. Re-verify the arrangement is still in force (it was provisional). Gibraltar also differs from Spain on plugs (Type G) and currency (Gibraltar pound). See [[entry-source-lessons]].
